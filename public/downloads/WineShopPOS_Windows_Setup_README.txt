WineShopPOS Windows customer package
====================================

Customer path:
Top-right user menu -> Account -> About -> Install WineShopPOS on Windows

Package:
WineShopPOS_Customer_Windows_Setup.zip

Contains:
- WineShopPOS_Windows_App_Setup.cmd
- WineShopPOS_Windows_App_Remove.cmd
- README.txt

The package always opens:
https://wineshoppos.z29.web.core.windows.net/

No Supabase keys, Azure keys, passwords, Git credentials or .env files are included.
