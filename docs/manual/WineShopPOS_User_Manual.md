# WineShopPOS User Manual

**Website:** https://wineshoppos.z29.web.core.windows.net/

## Roles
- **ADMIN:** full shop access; can create Manager/Cashier.
- **MANAGER:** products, inventory, purchases, reports, POS and sales.
- **CASHIER:** POS-focused access and intended own-sales view.

## Basic Sale
1. Login.
2. Open POS Billing.
3. Scan barcode.
4. Check cart.
5. Select Cash/UPI/Card.
6. Complete Sale.
7. Print invoice if required.

## Receive Stock
`Total bottles = cases x bottles per case + loose bottles`

Enter supplier, invoice number/date, product lines and purchase price, then Receive Stock.

## Support Messages
- **Account Disabled:** contact Shop Admin.
- **Shop Access Suspended:** contact software provider/platform owner.
