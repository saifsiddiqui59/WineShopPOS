# Chapter V2-10 — Full Application QA & Final Regression

Status: **Mandatory before V2 completion.**

Audit the whole app, not only V2 features:

- every reachable route
- every meaningful button/action
- forms
- tables
- modals/drawers
- loading/error/empty states
- ADMIN/MANAGER/CASHIER behavior
- multi-shop switching and isolation
- API/network failures
- browser console
- responsive management screens
- accessibility basics
- security attacks
- critical end-to-end business flows

A button is working only when click → backend/auth/db/UI/feedback all behave
correctly for the action.
